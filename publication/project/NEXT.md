**后续结果已收齐。** 新规则三条整网梯度/三Adam、主形状门禁及全部9点screen均通过。same/alternating/random中作者选择相对固定分组分别慢0.62%/0.34%/1.53%，每点仅一个独立进程。same产生180/400跨层波次；alternating实际任务/波次清单与固定分组完全相同；random为104/400跨层。当前没有达到继续扩大正式矩阵的选择收益信号，108矩阵仍关闭。适用范围仅本银行MaxVio10、GA4/W2和当前MegaMoE适配。

下一项应是受控成本定位，而不是给现有策略改名：独立比较相同任务顺序下32/64home域的真实前反向及保存态成本，用原AscendTimerV2补齐owner服务结束/依赖；区分统计开销、kernel非线性和域转换。现有home-plane几何计数不是实际梯度字节，Native legacy的checkpoint也不同，不能直接作纯复制成本归因。执行器若阻止潜力兑现，先验证执行边界；取得可重复因果证据后才进入联合策略。该诊断和新策略目前未完成。

筛查后的决策先固定：

- 固定分组/FIFO若解释全部在线改善，记录该工程结果；不能把观察成本离线消融当联合策略胜出。
- Easy仅在人工交替热点有效时，限定机制结论，并要求独立银行/自然router证据。
- 观察成本较大时，先研究合法的前缀复用；改变checkpoint划分会改变共同训练配方，须向全部基线开放并重新验收，不能只优化新方法。
- 缓存计划不等于缓存BF16专家权重。Afore-style实现仍需要layer/expert/optimizer版本、物理槽位、重放恢复和失效协议；当前未实现。
- 只有强基线出现可重复失效后才写新联合算法。正式参数冻结前保持108矩阵关闭，不按筛查结果更换测试路由。

1. **数值稳定性。** 新版本恢复 routed→shared 的原始图构建顺序。旧版本在 HC scale 上的2.08%/2.24%超限不能删除；新版本一次通过也不能认定根因已证明。若仍有超限，固定同一任务的 prefix 输入、FFN 输出及其上游梯度，分别比较普通/分组的 FFN 与 HC Jacobian，区分 BF16 累加顺序、FSDP 生命周期和重放问题。不能仅比较总梯度范数。

2. **原始顺序的真实成本。** 新 shared 后置使用额外的公开 layer 前向以获得 FSDP 参数。检查其 unshard/reshard 次数，所有额外通信算进整步。恢复顺序可能改善数值，但不等于提高性能。

3. **W2 可行性 pilot。** 所有 W2 小形状当前代码通过后，固定 MaxVio10/random，先无探测 Native、后 Easy-home，各新进程25次更新，5预热+20测量，保持L4/H4096/F1024/GA4。只有一轮、两个策略，不选“最快一轮”，不算108次正式矩阵。若真实内存门槛失败则停止，不缩模型。

4. **三类时间相关性筛查。** 同热点定义为同一step/layer内microbatch之间热点相同，层间置换独立；必须同时记录rank聚合负载，不能只看expert MaxVio。先补强固定分组、FIFO、独立复制和真正的Afore-style缓存。再选最强基线，不能先假设Native在新形状上仍最强。

5. **区分两项训练特有的潜在代价。**

   - 跨层组有64个home专家，在16K Native行上限下拆成多波，每个活跃副本/层域仍承担完整梯度义务，不能按token比例缩小估计。
   - 一次Native autograd节点同时返回多个任务的输出，当前计划只允许一次反向。因此跨microbatch分组可能引入反向汇合：不能先对一个输出随意backward，再假设同一ticket可为另一个输出再次backward。当前代码用窗口loss之和一次反向保证合法，但也保留了整个窗口的图。

   第二点是从当前接口得到的依赖约束，不是已经测得的关键路径归因。W4 OOM本身不足以证明是它造成。需要固定共同容量，比较相同W4就绪窗口下的独立执行、二任务组、四任务组，记录保存态、梯度就绪和真实内存寿命；不能把W2和W4的模型/输入混换后解释机制。

6. **有动机后才设计联合策略。** 如果实测显示分组造成了可重复的反向等待或资源占用，可把“分组引入的梯度汇合及保存态占用”纳入候选任务集合的代价，再比较等待互补任务与复制专家的选择。该想法仍需对照Tessera、Afore、PlaceMoE等，不能把deadline、内存约束或梯度重叠本身当作创新。当前未实现这种策略。

7. **性能结论。** 单轮pilot只能报告观察值。按原计划补三种相关性、六档MaxVio、独立重复、未调参银行和有条件消融；没有稳定收益就报告无稳定收益。
