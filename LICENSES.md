# Component licensing

This repository aggregates existing source snapshots. It does not replace the licenses of those components with a new blanket license.

- Native MegaMoE: preserve the license notices in `source/native-balanced/` and algorithm notices in `docs/planner-licenses/` within that component.
- FSDPTurbo: see `source/FSDPTurbo/LICENSE` and its source notices.
- MindSpeed-LLM: see `source/MindSpeed-LLM/LICENSE` and its source notices.
- Vendored CATLASS, CatCCOS and SHMEM: preserve each directory's own license and copyright notices under `source/native-balanced/3rdparty/`.
- Planner research reference files: see `references/Megatron-LICENSE`, `references/UltraEP-LICENSE` and the Native planner port notice.

Exact component revisions and optional upstream development dependencies are listed in `COMPONENTS.json`.
